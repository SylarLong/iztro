IZTRO

一套輕量級獲取紫微斗數排盤信息的 Javascript 開源庫。

前言 ​

歡迎使用 iztro 開發文檔！本頁將向你介紹如何集成、如何獲取數據、以及如何快速得到紫微斗數裏一張星盤上的所有數據。如果你只是基礎使用者，閱讀完本篇文檔將足夠你日常使用。 如果你已經掌握了本頁內容，可以到其他頁面進行更深入的探索。如果你對紫微斗數感興趣，但是又沒有相關基礎，可以點擊 基礎知識掃盲 進行掃盲學習。

你將獲取到以下信息：

  • 如何將 iztro 安裝和集成到你的代碼裏
  • 如何獲取到一張星盤
  • 如何基於星盤開始分析宮位
  • 如何基於宮位開始分析星曜

安裝 ​

使用包管理安裝 ​

你可以使用任意一種你熟悉的包管理工具進行安裝

sh
npm install iztro -S

安裝順利的話，會在你的package.json依賴列表中找到iztro

json
"dependencies": {
  "iztro": "^1.1.0"
}

版本號可能會有所不同

純JS庫使用 ^2.0.4 ​

在 v2.0.4 版本以後，提供了 umd 格式的純 JavaScript 庫。可以下載 release 資源文件中的 🗜️iztro-min-js.tar.gz 壓縮包，其中包含壓縮後的 JavaScript 文件及對應的 sourcemap。

從 v2.6.0 開始，每次發佈會同時生成帶版本號的文件（例如 iztro-v2.6.0.min.js）和兼容舊引用方式的 iztro.min.js。生產環境建議使用帶版本號的文件，以避免新版本發佈後 CDN 地址指向不同內容。

當然，我們更推薦你直接使用 CDN 加速鏈接，你可以在下面列表中選擇一個，在沒有指定版本號的時候，會自動指向最新版本的代碼庫

  • jsdelivr

    • https://cdn.jsdelivr.net/npm/iztro/dist/iztro.min.js
    • https://cdn.jsdelivr.net/npm/iztro@2.6.2/dist/iztro-v2.6.2.min.js

  • unpkg

    • https://unpkg.com/iztro/dist/iztro.min.js
    • https://unpkg.com/iztro@2.6.2/dist/iztro-v2.6.2.min.js

你也可以使用如下規則來指定版本：

  • iztro@2
  • iztro@^2.6.2
  • iztro@2.6.2

開始使用 ​

引入代碼 ​

你可以根據下列方式將iztro引入你的代碼

ts
import { astro } from "iztro";

讀取版本號 ​

透過 version 可以讀取目前載入的 iztro 版本，方便在更新前後比對。版本來自套件內的 package.json，獨立 UMD 檔案開頭也保留版本號和 MIT 授權資訊。此 API 自 v2.6.4 起提供。

ts
import { version } from "iztro";
console.log(version);

獲取星盤數據 ​

在獲取紫微斗數星盤的時候，可以根據農曆或者陽曆日期來獲取，iztro提供了這兩種獲取方式，你可以根據你的需求使用，但我們更推薦你使用陽曆的方式來使用。 放心，陽曆和農曆在程序內部獲取到的數據是統一的。

使用 陽曆 有如下便利性：

  • 可以很方便的在出生證上查到
  • 可以使用日曆組件進行日期選擇
  • 現在很多人都無法記住農曆日期
  • 可以避免因為忽略了閏月而帶來的一系列問題
ts
import { astro } from "iztro";

// 使用陽曆日期取得星盤資料
const solarChart = astro.bySolar("2000-8-16", 2, "女", true, "zh-TW");

// 使用農曆日期取得星盤資料
const lunarChart = astro.byLunar("2000-7-17", 2, "女", false, true, "zh-TW");

console.log({ solar: solarChart.toJSON(), lunar: lunarChart.toJSON() });

捲動至此處時載入可執行範例。

你會發現以上bySolar和byLunar的返回值是一樣的， 這是因為byLunar方法在內部處理的時候，也是將日期轉化為陽曆以後調用bySolar方法。

方法定義 ​

  • 通過陽曆日期獲取星盤信息

    astro.bySolar(solarDateStr, timeIndex, gender, fixLeap, language)

    • 參數

      參數類型是否必填默認值說明
      solarDateStrstringtrue-陽曆日期【YYYY-M-D】
      timeIndexnumbertrue-出生時辰序號【0~12】，對應從早子時（0）一直到晚子時（12）的序號
      genderstringtrue-性別【男/女】
      fixLeapbooleanfalsetrue是否調整閏月。設為 true 時，閏月初一至十五按同名的普通月計算，十六日起按下一個月計算。例如閏二月十五按二月，十六按三月。
      languageLanguagefalsezh-CN返回資料使用指定語言。目前支援 zh-CN、zh-TW、en-US、ko-KR、ja-JP 和 vi-VN。

    • 返回值

      FunctionalAstrolabe

  • 通過農曆日期獲取星盤信息

    astro.byLunar(lunarDateStr, timeIndex, gender, isLeapMonth, fixLeap, language)

    • 參數

      參數類型是否必填默認值說明
      lunarDateStrstringtrue-農曆日期【YYYY-M-D】，例如2000年七月十七則傳入2000-7-17
      timeIndexnumbertrue-出生時辰序號【0~12】，對應從早子時（0）一直到晚子時（12）的序號
      genderstringtrue-性別【男/女】
      isLeapMonthbooleanfalsefalse是否閏月，當實際月份沒有閏月時該參數不生效
      fixLeapbooleanfalsetrue是否調整閏月。設為 true 時，閏月初一至十五按同名的普通月計算，十六日起按下一個月計算。例如閏二月十五按二月，十六按三月。
      languageLanguagefalsezh-CN返回資料使用指定語言。目前支援 zh-CN、zh-TW、en-US、ko-KR、ja-JP 和 vi-VN。

    • 返回值

      FunctionalAstrolabe

獲取運限 ​

在 iztro 中，horoscope() 會回傳 大限、小限、流年、流月、流日 和 流時。流分 和 流秒 目前尚未提供。小限依虛歲逐年移宮，流年則依當年地支定位，兩者的排法不同。

ts
import { astro } from "iztro";

// 使用陽曆日期取得星盤資料
const astrolabe = astro.bySolar("2000-8-16", 2, "女", true, "zh-TW");

// 取得運限資料
console.log(astrolabe.horoscope(new Date()).toJSON());

捲動至此處時載入可執行範例。

Tips: 上面的運限數據和你調用的會因為傳入的時間參數不同而不同，但是結構上是一致的。

方法定義 ​

  • 獲取當前星盤的運限信息

    astrolabe.horoscope(date, timeIndex)

    • 參數

      參數類型是否必填默認值說明
      datestring | Datefalsenew Date()陽曆日期字符串或日期對象，若時間字符串或日期對象中包含了小時的信息，timeIndex可以省略
      timeIndexnumberfalse0時辰序號，若不傳該參數則會嘗試從date裏獲取小時信息轉化為時辰序號

    • 返回值

      Horoscope

獲取流曜 ​

上面的horoscope()方法內已經包含了大限和流年的流曜，所以一般情況下無需再單獨調用獲取流曜的方法，但也有例外的情況需要自行獲取流曜，那就需要調用下列方法自行獲取。

ts
import { astro, star } from "iztro";

astro.config({ language: "zh-TW" });

// 使用天干與地支取得流曜
const horoscopeStars = star.getHoroscopeStar("庚", "辰", "decadal");
console.log(horoscopeStars.map((stars) => stars.map((item) => item.toJSON())));

捲動至此處時載入可執行範例。

方法定義 ​

  • 通過 天干、地支 獲取流曜

    star.getHoroscopeStar(heavenlyStem, earthlyBranch, scope)

    • 參數

      參數類型是否必填默認值說明
      heavenlyStemHeavenlyStemNametrue-天干
      earthlyBranchEarthlyBranchNametrue-地支
      scope'decadal' | 'yearly'true-限定是大限還是流年的流曜，其中大限流曜會在星曜前面加上運，流年流曜會在星曜前面加上流，年解比較特殊，只會出現在流年的流曜裏

    • 返回值

      Star[][]

타입 정의 ​

서문 ​

이 페이지에서는 iztro의 타입 정의를 설명합니다. 국제화 타입은 i18n에 정의되어 있으며, 나머지 타입은 types에 정의되어 있습니다.

다음 코드로 국제화 타입을 가져올 수 있습니다:

ts
import { HeavenlyStemName } from "iztro/lib/i18n";

다른 타입은 다음과 같이 가져옵니다:

ts
import { Palace } from "iztro/lib/data/types";

팁

번역이나 타입 정의에서 오류나 부적절한 내용을 발견하면 이슈를 등록해 주세요. 감사합니다!

국제화 타입 ​

iztro는 다국어 입력과 출력을 지원하기 위해 매개변수와 결과 값에 여러 언어의 이름을 정의합니다. 입력값은 지원되는 어떤 언어로도 지정할 수 있습니다. 예를 들어 HeavenlyStemName에는 甲, 갑, jia를 전달할 수 있습니다.

예를 들어 getHoroscopeStar()를 호출할 때 천간（天干）과 지지（地支）의 중국어 이름을 인수로 전달할 수 있습니다:

ts
import { getHoroscopeStar } from "iztro/lib/star";

getHoroscopeStar("甲", "子", "decadal");

다른 지원 언어의 이름을 인수로 전달하거나, 한 번의 호출에서 여러 언어를 섞어 사용할 수도 있습니다:

ts
import { getHoroscopeStar } from "iztro/lib/star";

getHoroscopeStar("갑", "zi", "decadal");

입력에 어떤 언어를 사용하든 출력은 지정한 언어로 통일됩니다. 메서드를 호출하기 전에 출력 언어를 설정하세요:

ts
import { setLanguage } from "iztro/lib/i18n";

setLanguage("ko-KR");

const horoscopeStar = getHoroscopeStar("甲", "zi", "decadal");

이때 horoscopeStar의 출력 결과는 한국어가 됩니다.

공통 타입 ​

Language ​

ts
export type Language = `zh-CN` | `zh-TW` | `en-US` | `ko-KR` | `ja-JP` | `vi-VN`;

지원되는 언어가 정의됩니다. 현재 지원되는 언어는 다음과 같습니다.

  • zh-CN: 중국어 간체
  • zh-TW: 중국어(번체)
  • en-US：English
  • ko-KR：한국어
  • ja-JP: 일본어
  • vi-VN: 베트남어

Scope ​

ts
export type Scope = "origin" | "decadal" | "yearly";

성요（星曜）의 적용 범위를 정의하여 본명 성요（本命星曜）와 유요（流曜）를 구분합니다:

  • origin: 본명 성요（本命星曜）
  • decadal: 대한 성요（大限星曜）
  • yearly: 유년 성요（流年星曜）

StarType ​

ts
export type StarType =
  | "major"
  | "soft"
  | "tough"
  | "adjective"
  | "flower"
  | "helper"
  | "lucun"
  | "tianma";

성요（星曜）의 유형을 정의합니다. 도화성（桃花星）과 해신（解神）(해신(년)（年解） 포함)은 잡요（雜曜）이지만 명반 해석에서 특별한 의미가 있어 별도로 분류합니다. 두 보조 성요인 록존（祿存）과 천마（天馬）도 특수한 역할이 있어 각각 따로 분류합니다:

  • major: 주성（主星）
  • soft: 길성（吉星）
  • tough: 살성（煞星）
  • adjective: 잡요（雜曜）
  • flower: 도화성（桃花）
  • helper：해신（解神）
  • lucun：록존（祿存）
  • tianma：천마（天馬）

설정과 플러그인 ^2.3.0 ​

ConfigMutagens ​

전역 구성에서 사화（四化） 매개변수를 정의합니다.

ts
type ConfigMutagens = Partial<Record<HeavenlyStemName, StarName[]>>;

ConfigBrightness ​

전역 구성에서 밝기 매개변수를 정의합니다.

ts
type ConfigBrightness = Partial<Record<StarName, Brightness[]>>;

Config ​

명반 계산 설정 객체를 정의합니다. astro.config()로 이후 생성할 명반의 기본값을 설정하거나, withOptions({ config })로 지금 생성하는 명반에만 다른 설정을 적용할 수 있습니다. 이미 생성된 명반은 생성 당시의 설정을 유지합니다(^2.6.2).

ts
type Config = {
  // 星曜四化配置
  mutagens?: ConfigMutagens;
  // 星曜亮度配置
  brightness?: ConfigBrightness;
  // 年分割点配置
  yearDivide?: 'normal' | 'exact';
  // 运限分割点配置（^v2.4.3）
  horoscopeDivide?: 'normal' | 'exact';
  // 小限分割点配置，normal为以自然年分界，birthday为生日分界（^v2.4.5）
  // 默认为 normal
  ageDivide?: 'normal' | 'birthday';
  // 晚子时配置，current 时晚子时算当日，forward 时晚子时算次日（^v2.5.2）
  // 默认为 forward
  dayDivide?: 'current' | 'forward';
  // 安星方法，default 为通行版本，zhongzhou 为中州派版本（^v2.5.0）
  // 默认为 default
  algorithm?: 'default' | 'zhongzhou';
};

yearDivide와 horoscopeDivide의 값이 normal이면 음력 정월 초하루를 연도의 경계로 사용하고, exact이면 절기인 입춘（立春）을 경계로 사용합니다.

dayDivide는 만자시（晚子時）(timeIndex가 12인 경우)를 어느 날짜에 포함할지만 결정합니다. forward는 다음 날에, current는 당일에 포함합니다.

AstroType ^2.5.0 ​

중주파（中州派） 명반의 타입을 정의합니다.

ts
type AstroType = 'heaven' | 'earth' | 'human';
값설명
heaven천반, 기본값
earth지반: 신궁의 간지로 오행국을 정하고, 신궁을 명궁으로 삼습니다.
human인반: 복덕궁의 간지로 오행국을 정하고, 복덕궁을 명궁으로 삼습니다.

Plugin ​

플러그인 타입을 정의합니다. 플러그인은 하나의 함수입니다.

ts
type Plugin = () => void;

팁

플러그인 함수는 this 매개변수를 암묵적으로 받으며, 그 타입은 T extends FunctionalAstrolabe입니다. 만드는 방법은 플러그인을 참고하세요.

IZTRO

자미두수（紫微斗數） 명반 데이터를 얻기 위한 가벼운 JavaScript 오픈 소스 라이브러리입니다.

서문 ​

iztro 개발 문서에 오신 것을 환영합니다! 이 페이지에서는 라이브러리 연동 방법, 데이터 조회 방법, 자미두수（紫微斗數） 명반（星盤）의 모든 데이터를 빠르게 얻는 방법을 설명합니다. 기본적인 기능을 일상적으로 사용하려면 이 문서의 내용으로 충분합니다. 내용을 익힌 뒤에는 다른 페이지에서 더 자세히 살펴보세요. 자미두수에 관심은 있지만 기초 지식이 없다면 기초 지식부터 읽어 보세요.

다음 정보를 얻게 됩니다:

  • iztro를 코드에 설치하고 통합하는 방법
  • 명반（星盤）을 얻는 방법
  • 명반（星盤）을 바탕으로 궁위（宮位）를 분석하는 방법
  • 궁위（宮位） 데이터를 바탕으로 성요（星曜）를 분석하는 방법

설치 ​

패키지 관리자로 설치하기 ​

익숙한 패키지 관리 도구를 사용하여 설치할 수 있습니다.

sh
npm install iztro -S

설치가 완료되면 package.json의 의존성 목록에서 iztro를 확인할 수 있습니다.

json
"dependencies": {
  "iztro": "^1.1.0"
}

버전 번호는 다를 수 있습니다.

순수 JS 라이브러리 사용 ^2.0.4 ​

v2.0.4 버전 이후에는 umd 형식의 순수 JavaScript 라이브러리가 제공됩니다. 릴리스 첨부 파일에서 🗜️iztro-min-js.tar.gz를 다운로드하세요. 이 압축 파일에는 압축된 JavaScript 파일과 해당 소스 맵이 들어 있습니다.

v2.6.0부터 각 릴리스는 버전 번호가 포함된 파일(예: iztro-v2.6.0.min.js)과 기존 참조 방식에 호환되는 iztro.min.js를 함께 생성합니다. 새 버전이 출시된 뒤 같은 CDN 주소가 다른 내용을 제공하는 일을 피하려면, 운영 환경에서는 버전 번호가 포함된 파일을 사용하는 것이 좋습니다.

아래 주소를 사용하면 CDN에서 라이브러리를 직접 불러올 수 있습니다. 버전 번호를 지정하지 않은 주소는 최신 버전을 제공합니다.

  • jsdelivr

    • https://cdn.jsdelivr.net/npm/iztro/dist/iztro.min.js
    • https://cdn.jsdelivr.net/npm/iztro@2.6.2/dist/iztro-v2.6.2.min.js

  • unpkg

    • https://unpkg.com/iztro/dist/iztro.min.js
    • https://unpkg.com/iztro@2.6.2/dist/iztro-v2.6.2.min.js

다음 규칙을 사용하여 버전을 지정할 수도 있습니다.

  • iztro@2
  • iztro@^2.6.2
  • iztro@2.6.2

시작하기 ​

라이브러리 가져오기 ​

다음과 같이 코드에 iztro를 도입할 수 있습니다.

ts
import { astro } from "iztro";

명반 데이터 가져오기 ​

자미두수（紫微斗數） 명반（星盤）은 음력 또는 그레고리력 날짜로 만들 수 있습니다. iztro는 두 방식을 모두 지원하지만, 그레고리력 방식을 권장합니다. 같은 날짜를 입력하면 두 방식 모두 같은 명반 데이터를 반환합니다.

양력 날짜를 사용하면 다음과 같은 장점이 있습니다.

  • 출생증명서를 통해 쉽게 확인할 수 있습니다.
  • 달력에서 날짜를 고르는 입력 도구를 사용할 수 있습니다.
  • 요즘은 음력 날짜를 기억하기 어려워하는 사람이 많습니다.
  • 윤달을 무시함으로써 발생하는 일련의 문제를 피할 수 있습니다.
ts
import { astro } from "iztro";

// 通过阳历获取星盘信息
const astrolabe = astro.bySolar("2000-8-16", 2, "女");

// 通过农历获取星盘信息
const astrolabe = astro.byLunar("2000-7-17", 2, "女");

위의 bySolar와 byLunar 호출은 같은 결과를 반환합니다. byLunar는 내부적으로 날짜를 그레고리력으로 변환한 뒤 bySolar를 호출하기 때문입니다. 아래의 실행 결과는 길어서 접어 두었습니다. 펼쳐서 자신의 호출 결과와 비교할 수 있습니다.

메서드 정의 ​

  • 양력 날짜로 명반（星盤） 정보 얻기

    astro.bySolar(solarDateStr, timeIndex, gender, fixLeap, language)

    • 매개변수

      매개변수타입필수 여부기본값설명
      solarDateStrstringtrue-그레고리력 날짜【YYYY-M-D】
      timeIndexnumbertrue-출생 시진 인덱스 [0–12]. 조자시(0)부터 만자시(12)까지에 대응합니다.
      genderstringtrue-성별【남성/여성】
      fixLeapbooleanfalsetrue윤달 조정 여부. true이면 윤달의 전반부는 이전 달, 후반부는 다음 달로 계산합니다.
      languageLanguagefalsezh-CN반환 데이터에 사용할 언어입니다. zh-CN, zh-TW, en-US, ko-KR, ja-JP, vi-VN을 지원합니다.

    • 반환 값

      FunctionalAstrolabe

  • 음력 날짜로 명반（星盤） 정보 얻기

    astro.byLunar(lunarDateStr, timeIndex, gender, isLeapMonth, fixLeap, language)

    • 매개변수

      매개변수타입필수 여부기본값설명
      lunarDateStrstringtrue-음력 날짜 [YYYY-M-D]. 예를 들어 2000년 7월 17일이면 2000-7-17을 전달합니다.
      timeIndexnumbertrue-출생 시진 인덱스 [0–12]. 조자시(0)부터 만자시(12)까지에 대응합니다.
      genderstringtrue-성별【남성/여성】
      isLeapMonthbooleanfalsefalse입력한 음력 월이 윤달인지 여부. 해당 월에 윤달이 없으면 이 매개변수는 적용되지 않습니다.
      fixLeapbooleanfalsetrue윤달 조정 여부. true이면 윤달의 전반부는 이전 달, 후반부는 다음 달로 계산합니다.

    • 반환 값

운한 데이터 가져오기 ​

자미두수（紫微斗數）의 운한은 대한（大限）, 유년（流年）, 유월（流月）, 유일（流日）, 유시（流時）, 분 단위 운한（流分）, 초 단위 운한（流秒）으로 나뉩니다. 분 단위 운한（流分）과 초 단위 운한（流秒）은 사용되는 경우가 적어 현재는 제공하지 않습니다. 대한（大限）, 유년（流年）, 유월（流月）, 유일（流日）, 유시（流時）로 대부분의 요구 사항을 충족할 수 있으며, iztro를 사용하면 이러한 데이터를 쉽게 얻을 수 있습니다.

ts
import { astro } from "iztro";

// 通过阳历获取星盘信息
const astrolabe = astro.bySolar("2000-8-16", 2, "女");

// 获取运限数据
astrolabe.horoscope(new Date());

유요（流曜） 데이터 가져오기 ​

horoscope()의 결과에는 대한（大限）과 유년（流年）의 유요（流曜）가 이미 포함됩니다. 보통은 별도로 조회할 필요가 없습니다. 따로 조회해야 하는 경우에는 다음 메서드를 사용하세요.

ts
import { star } from "iztro";

// 通过天干地支获取流曜
const horoscopeStars = star.getHoroscopeStar("庚", "辰", "decadal");

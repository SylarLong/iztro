궁（宮位） ​

서문 ​

자미두수（紫微斗數）에는 열두 개의 궁이 있으며, 이를 통틀어 십이 인사궁（十二人事宮）이라고 합니다. 한 사람과 관련된 사람들과 삶의 여러 영역을 나타냅니다. 순서대로 명궁（命宮）, 형제（兄弟）, 부처（夫妻）, 자녀（子女）, 재백（財帛）, 질액（疾厄）, 천이（遷移）, 노복（僕役）, 관록（官祿）, 전택（田宅）, 복덕（福德）, 부모（父母）입니다. 명반에 표시되는 이 열두 궁 외에 신궁（身宮）, 래인（來因）, 암합궁（暗合宮）이라는 세 개의 숨은 궁도 있습니다. 각 궁의 의미는 이 API 페이지에서 자세히 다루지 않습니다. 기본 개념이나 더 자세한 설명은 궁 체계를 참고하세요. 지지는 시계 방향으로 배치되지만 궁의 이름은 반시계 방향으로 배치됩니다. 아래 표는 그 예입니다:

사（巳）전택（田宅）오（午）관록（官祿）미（未）노복（僕役）신（申）천이（遷移）
진（辰）복덕（福德）중궁유（酉）질액（疾厄）
묘（卯）부모（父母）술（戌）재백（財帛）
인（寅）명궁（命宮）축（丑）형제（兄弟）자（子）부처（夫妻）해（亥）자녀（子女）

위 표는 하나의 예입니다. 명궁（命宮）의 위치는 생년월일과 출생 시간에 따라 달라지며, 위의 열두 자리 중 어디에나 놓일 수 있습니다. 다만 궁 이름의 순서는 바뀌지 않습니다.

궁위라는 말은 궁과 위치라는 두 개념을 합친 것입니다. 생년월일과 출생 시간으로 계산하여 정해지는 것이 궁입니다. 따라서 출생 명반에서 재백（財帛）궁의 자리는 고정됩니다. 본명반（本命盤）이라는 개념이 낯설다면 먼저 기초 지식을 읽어 보세요. 반면 위치는 기준 궁에 따라 정해지는 상대적인 위치입니다. 예를 들어 부처（夫妻）궁을 기준으로 잡으면 그 재백 위치（財帛位）에 해당하는 궁은 천이（遷移）궁입니다. 복잡하게 느껴질 수 있지만, 모든 관계를 외울 필요 없이 두 개념의 차이만 이해하면 됩니다.

클래스와 분석 메서드 ​

개발 제안

궁은 명반에 속하므로 new로 궁 객체를 직접 생성하기보다는 정적 명반 생성 메서드가 반환한 명반의 궁 객체를 사용하세요. 명반의 palaces 속성에는 열두 궁의 데이터가 들어 있습니다. 지지 순서에 맞춰 인궁（寅宮）부터 시계 방향으로 배열됩니다.

ts
import { astro } from "iztro";

const astrolabe = astro.astrolabeBySolarDate("2000-8-16", 2, "女", true, "zh-CN");

위의 astrolabe 변수에서 여러 가지 방법으로 대상 궁을 얻을 수 있습니다. 실제 필요에 따라 사용하십시오.

  1. palaces 배열의 인덱스로 가져오기

    ts
    // 获取卯宫宫位
const palace = astrolabe.palaces[1];

  2. FunctionalAstrolabe 인스턴스의 palace() 메서드에 궁의 색인을 전달하여 가져옵니다.

    ts
    // 获取卯宫宫位
const palace = astrolabe.palace(1);

  3. FunctionalAstrolabe 인스턴스의 palace() 메서드에 궁의 이름을 전달하여 가져옵니다.

    ts
    // 获取命宫
const palace = astrolabe.palace("命宫");

FunctionalPalace ​

implements IFunctionalPalace extends Palace

이 클래스는 Palace의 속성을 상속하고, 궁 안의 성요를 분석하는 메서드를 추가합니다.

  • 인터페이스 정의

    ts
    interface IFunctionalPalace extends Palace {
  toJSON: () => Palace;
  has: (stars: StarName[]) => boolean;
  notHave: (stars: StarName[]) => boolean;
  hasOneOf: (stars: StarName[]) => boolean;
  hasMutagen: (mutagen: Mutagen): boolean;
  notHaveMutagen: (mutagen: Mutagen): boolean;
  isEmpty: (excludeStars?: StarName[]) => boolean;
  astrolabe: () => IFunctionalAstrolabe | undefined;
  fliesTo: (to: number | PalaceName, withMutagens: Mutagen | Mutagen[]) => boolean;
  fliesOneOfTo: (to: number | PalaceName, withMutagens: Mutagen[]) => boolean;
  notFlyTo: (to: number | PalaceName, withMutagens: Mutagen | Mutagen[]) => boolean;
  selfMutaged: (withMutagens: Mutagen | Mutagen[]) => boolean;
  selfMutagedOneOf: (withMutagens?: Mutagen[]) => boolean;
  notSelfMutaged: (withMutagens?: Mutagen | Mutagen[]) => boolean;
  mutagedPlaces: () => (IFunctionalPalace | undefined)[];
}

  • 속성

    참조 Palace

  • 메서드

    toJSON() ^2.6.0 ​

    • 목적

      분석 기능이 있는 궁 객체를 일반 JSON 객체로 변환합니다. 반환 결과에는 분석 메서드나 연결된 명반 등의 실행 시 참조가 포함되지 않습니다. 순환 참조는 안전하게 제외합니다.

    • 정의

      ts
      type toJSON = () => Palace;

    • 매개변수

      없음

    • 반환 값

      Palace

    • 예

      ts
      const data = astrolabe.palace("命宫")?.toJSON();

    has() ^1.0.0 ​

    • 목적

      궁에 지정한 성요（星曜）가 있는지 확인합니다. 지정한 모든 별이 궁 안에 모두 있어야 true를 반환합니다.

    • 정의

      ts
      type has = (stars: StarName[]) => boolean;

    • 매개변수

      매개변수타입필수 여부기본값설명
      starsStarName[]true-성요 이름. 주성（主星）, 보조성（輔星）, 잡요（雜曜）를 지정할 수 있습니다.

    • 반환 값

      boolean

    • 예

      명궁（命宮）에 자미（紫微） 및 우필（右弼）이 있는지 확인하려면

      ts
      const palace = astrolabe.palace("命宫");
const result = palace.has(["紫微", "右弼"]);

      메서드 체이닝을 사용하면 코드를 더 간결하게 작성할 수 있습니다.

      ts
      const result = astrolabe.palace("命宫").has(["紫微", "右弼"]);

    notHave() ^1.0.0 ​

    • 목적

      궁에 지정한 성요（星曜）가 없는지 확인합니다. 지정한 별이 하나도 없어야 true를 반환합니다.

      boolean

    have() ​

    • 목적

      궁의 삼방사정（三方四正） 안에 지정한 성요（星曜）가 있는지 확인합니다. 지정한 모든 별이 이 범위에 모두 있어야 true를 반환합니다.

    • 정의

      ts
      type have = (stars: StarName[]) => boolean;

    • 매개변수

      매개변수타입필수 여부기본값설명
      starsStarName[]true-성요 이름. 주성（主星）, 보조성（輔星）, 잡요（雜曜）를 지정할 수 있습니다.

    • 반환 값

      boolean

    • 예

      명궁（命宮）의 삼방사정（三方四正） 안에 자미（紫微）와 우필（右弼）이 모두 있는지 확인하려면:

      ts
      const palaces = astrolabe.surroundedPalaces("命宫");
const result = palaces.have(["紫微", "右弼"]);

      메서드 체이닝을 사용하면 코드를 더 간결하게 작성할 수 있습니다.

      const result = astrolabe.surroundedPalaces("命宫").have(["紫微", "右弼"]);

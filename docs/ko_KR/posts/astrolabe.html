명반（星盤） ​

서문 ​

자미두수（紫微斗數） 명반은 열두 궁과 중궁으로 구성됩니다. 각 궁의 지지（地支）는 고정되어 있고, 순서는 인（寅）에서 시작하며 자（子）에서 시작하지 않습니다. 음력 정월이 인（寅）월이기 때문이며, 이를 음력 정월은 인에 대응한다（正月建寅）라고 합니다. iztro에서는 인궁（寅宮）의 인덱스가 0, 묘궁（卯宮）의 인덱스가 1이고, 이후 시계방향으로 이어집니다. 아래 표를 참고하세요:

사（巳）3오（午）4미（未）5신（申）6
진（辰）2중궁유（酉）7
묘（卯）1술（戌）8
인（寅）0축（丑）11자（子）10해（亥）9

중궁에는 원하는 정보를 표시할 수 있으며, 보통 명반 전체의 해석에는 영향을 주지 않습니다. 주변의 십이궁（十二宮）에는 성요（星曜）, 사화（四化）, 운한（運限）, 궁 이름 등의 정보가 들어갑니다. 궁（宮位）의 자세한 내용은 궁 설명을 참고하세요. 이 페이지는 명반 전체의 정보를 다룹니다. 명반은 궁과 별로 구성되므로, 개념이 낯설다면 기초 지식부터 공부해 보세요.

iztro를 설치한 다음 아래 코드로 명반 (astro) 객체를 가져올 수 있습니다. iztro 설치 방법은 설치 안내를 참고하세요.

astro의 정적 메서드 ​

객체의 정적 메서드를 사용하려면 먼저 import로 코드에 가져오세요.

ts
import { astro } from "iztro";

명반 설정과 입력값 검증 ^2.6.2 ​

bySolar, byLunar, withOptions가 반환하는 명반은 생성 당시의 설정과 언어를 저장합니다. 전역 기본 설정을 바꾸거나 다른 언어의 명반을 만들어도 기존 명반의 운한（運限）과 사화（四化） 분석은 바뀌지 않습니다.

withOptions의 type은 생략할 수 있으며 기본값은 양력입니다. config는 해당 명반의 설정만 덮어씁니다. 명반 생성과 날짜 보조 메서드에서 language를 생략하면 zh-CN을 사용하고, 특정 언어를 지정해도 다른 호출의 언어에는 영향을 주지 않습니다. 지원 값은 zh-CN, zh-TW, en-US, ja-JP, ko-KR, vi-VN입니다.

연도는 1~9999여야 하며 양력이나 음력에 실제로 존재하는 날짜여야 합니다. 날짜 문자열은 하이픈, 슬래시, 마침표로 구분할 수 있고 HH:mm 또는 HH:mm:ss를 덧붙일 수 있습니다. 과거 양력 날짜는 기반 달력의 율리우스력·그레고리력 전환 규칙을 따릅니다. 시각 인덱스는 0~12의 정수여야 합니다. 알 수 없는 성별·언어·날짜 유형·명반 유형이나 불리언이 아닌 윤달 옵션은 오류를 발생시킵니다. 음력 날짜는 실제 월별 일수로 검증하고, 윤달이 없는 달에는 isLeapMonth: true를 무시합니다.

설정의 적용 범위, getConfig()가 반환하는 독립 복사본, resetConfig()에 대해서는 설정과 플러그인을 참고하세요.

  • 예제

    ts
    import { astro } from "iztro";

FunctionalAstrolabe ​

implements IFunctionalAstrolabe extends Astrolabe

이 클래스는 Astrolabe의 속성을 상속하고 명반 분석 메서드를 추가합니다. bySolar()와 byLunar()는 이 클래스의 인스턴스를 반환합니다.

  • 인터페이스 정의

  decadalList: () => DecadalHoroscope[];
  yearlyList: (indexOrName: number | PalaceName) => YearlyHoroscope[];
  monthlyList: (year: number, fixLeap?: boolean) => MonthlyHoroscope[];
  palace: (indexOrName: number | PalaceName) => IFunctionalPalace | undefined;
  surroundedPalaces: (indexOrName: number | PalaceName) => SurroundedPalaces;
  isSurrounded: (
    indexOrName: number | PalaceName,
    stars: StarName[]
  ) => boolean;
  isSurroundedOneOf: (
    indexOrName: number | PalaceName,
    stars: StarName[]
  ) => boolean;
  notSurrounded: (
    indexOrName: number | PalaceName,
    stars: StarName[]
  ) => boolean;
  hasMutagenInSurroundedPalace: (

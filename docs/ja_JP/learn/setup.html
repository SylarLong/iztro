紫微斗数の安星訣 ​

はじめに ​

安星訣は、紫微斗数のデータを計算する算法です。古典では覚えやすい口訣にまとめられています。まずその口訣を掲載し、後から詳しく解説する予定です。余暇に一人で更新するのは大変なので、サイトへのご支援をご検討ください。

ヒント

この章には基礎知識が必要です。初めての方は、先に基礎知識を学んでから読むことをおすすめします。

ドキュメントの執筆には時間と労力がかかります。お役に立ちましたら、

安星訣 ​

1. 寅宮の天干の算出法 ​

甲己年生起丙寅，

乙庚年生起戊寅，

丙辛年生起庚寅，

丁壬年生起壬寅，

戊癸年生起甲寅。

2. 命宮と身宮の配置法 ​

寅起正月，順數至生月，逆數生時為命宮。

寅起正月，順數至生月，順數生時為身宮。

3. 十二宮の配置法 ​

由命宮逆數：兄弟、夫妻、子女、財帛、疾厄、遷移、奴僕、事業、田宅、福德、父母。

4. 大限の算出法 ​

大限由命宮起，

陽男陰女順行；

陰男陽女逆行，

每十年過一宮限。

5. 小限の算出法 ​

小限一年一度逢，男順女逆不相同，

寅午戌人辰上起，申子辰人自戌宮，

巳酉丑人未宮始，亥卯未人起丑宮。

6. 命主の算出法 ​

子屬貪狼丑亥門，

寅戌生人屬祿存。

卯酉屬文巳未武，

辰申廉宿午破軍。

ヒント

このライブラリの標準方式では、命宮が位置する宮の地支から命主を求めます。中州派のアルゴリズムでは、生年の地支を使います。

7. 身主の算出法 ​

子午安身鈴火宿，

丑未天相寅申梁，

卯酉天同身主是，

巳亥天機辰戌昌。

ヒント

身主は生年の地支から求めます。口訣は資料によって異なる場合があります。このライブラリでは、子年と午年の身主はいずれも火星です。

8. 紫微の配置法 ​

六五四三二，酉午亥辰丑，

局數除日數，商數宮前走；

若見數無餘，便要起虎口，

日數小於局，還直宮中守。

9. 天府の配置法 ​

天府南斗令，常對紫微宮，

丑卯相更迭，未酉互為根。

往來午與戌，蹀躞子和辰，

巳亥交馳騁，同位在寅申。

ヒント

紫微の位置を基準に定めます。

10. 紫微星系の配置法 ​

紫微逆去天機星，

隔一太陽武曲辰，

連接天同空二宮，

廉貞居處方是真。

11. 天府星系の配置法 ​

天府順行有太陰，

貪狼而後巨門臨，

隨來天相天梁繼，

七殺空三是破軍。

12. 五行局の算出法 ​

甲乙丙丁一到五，子丑午未一來數，

寅卯申酉二上走，辰巳戌亥三為足。

干支相加多減五，五行木金水火土。

注:

  1. 五行の数：木1、金2、水3、火4、土5。

    • 天干の数：

      • 甲・乙 → 1
      • 丙・丁 → 2
      • 戊・己 → 3
      • 庚・辛 → 4
      • 壬・癸 → 5

    • 地支の数：

      • 子・午・丑・未 → 1
      • 寅・申・卯・酉 → 2
      • 辰・戌・巳・亥 → 3

  2. 計算方法：

    天干と地支の数を足し、5を超えたら5を引きます。結果の1・2・3・4・5は木・金・水・火・土に対応します。

  3. 例:

    • 丙 + 子: 2+1=3 → 水 → 水の二局
    • 辛未：4+1=5 → 土 → 土五局。
    • 庚 + 申: 4+2=6 → 6−5=1 → 木 → 木の三局

13. 左輔・右弼・文昌・文曲・地空・地劫の配置法 ​

辰上順正尋左輔，戌上逆正右弼當，

辰上順時文曲位，戌上逆時覓文昌，

亥上子時順安劫，逆回便是地空亡。

14. 天魁・天鉞の配置法 ​

甲戊庚之年丑未，

乙己之年子申，

辛年午寅，

壬癸之年卯巳，

丙丁之年亥酉。

15. 禄存・擎羊・陀羅の配置法 ​

甲祿到寅宮，乙祿居卯府。

丙戊祿在巳，丁己祿在午。

庚祿定居申，辛祿酉上補。

壬祿亥中藏，癸祿居子戶。

祿前羊刃當，祿後陀羅府。

16. 天馬の配置法 ​

寅午戌年馬在申，申子辰年馬在寅。

巳酉丑年馬在亥，亥卯未年馬在巳。

ヒント

出生年の地支を基準にします。

17. 火星・鈴星の配置法 ​

申子辰人寅戌揚，寅午戌人丑卯方。

巳酉丑人卯戌位，亥卯未人酉戌房。

ヒント

火星と鈴星を置くには、まず出生年の地支から口訣に従って子時の起点を定めます。

壬辰年の卯時生まれなら、申子辰人寅戌揚に従い、火星は寅宮、鈴星は戌宮を子時の起点にします。卯時まで順に数えると、火星は巳宮、鈴星は丑宮に置かれます。

18. 四化星の配置法 ​

甲廉破武陽，乙機梁紫陰，

丙同機昌廉，丁陰同機巨，

戊貪陰右機。己武貪梁曲，

庚陽武陰同，辛巨陽曲昌，

壬梁紫左武，癸破巨陰貪。

ヒント

四化の配当は流派によって異なり、上記は南派の方式です。

19. 台輔・封誥の配置法 ​

臺輔午起子順到時，封誥寅宮起子逆到時。

20. 天刑・天姚の配置法 ​

天刑從酉起正月，順至生月便安之。

天姚丑宮起正月，順到生月即停留。

21. 解神の配置法 ​

  • 月解

    月解は出生月で配置します。

    正二在申三四在戌，

    五六在子七八在寅。

    九十月坐於辰宮，

    十一十二在午宮。

  • 年解

    年解は流年の解神で、流曜に属し、毎年位置が変わります。

    解神從戌上起子，逆數至當生年太歲上是也

22. 天巫の配置法 ​

正五九月在巳，二六十月在申，

三七十一在寅，四八十二在亥。

23. 天月の配置法 ​

一犬二蛇三在龍，四虎五羊六兔宮。

七豬八羊九在虎，十馬冬犬臘寅中。

24. 陰煞の配置法 ​

正七月在寅，二八月在子，

三九月在戌，四十月在申，

五十一在午，六十二在辰。

25. 截空の配置法 ​

甲己之年申酉，

乙庚之年午未，

丙辛之年辰巳，

丁壬之年寅卯，

戊癸之年子丑。

26. 天官・天福の配置法 ​

甲喜羊雞乙龍猴，丙年蛇鼠一窩謀。

丁虎擒豬戊玉兔，己雞居然與虎儔。

庚豬馬辛雞蛇走，壬犬馬癸馬蛇遊。

27. 天空の配置法 ​

生年支順數的前一位就是。

28. 天哭・天虚の配置法 ​

天哭天虛起午宮，午宮起子兩分蹤，

哭逆行兮虛順轉，數到生年便停留。

29. 竜池・鳳閣の配置法 ​

龍池從辰宮起子，

順至本生年支安之。

鳳閣從戌宮起子，

逆行至本生年支安之。

30. 紅鸞・天喜の配置法 ​

卯上起子逆數之，數到當生太歲支。

坐守此宮紅鸞位，對宮天喜不差移。

31. 孤辰・寡宿の配置法 ​

寅卯辰年安巳丑，巳午未年安申辰，

申酉戌年安亥未，亥子丑年安寅戌。

32. 蜚廉の配置法 ​

子丑寅年在申酉戌，卯辰巳年在巳午未，

午未申年在寅卯辰，酉戌亥年在亥子丑。

33. 破碎の配置法 ​

子午卯酉年安巳宮，

寅申巳亥年安酉宮，

辰戌丑未年安丑宮。

34. 華蓋の配置法 ​

子辰申年在辰，丑巳酉年在丑，

寅午戌年在戌，卯未亥年在未。

35. 咸池の配置法 ​

子辰申年在酉，丑巳酉年在午，

寅午戌年在卯，卯未亥年在子。

36. 天才・天寿の配置法 ​

天才由命宮起子，順行至本生年支安之。

天壽由身宮起子，順行至本生年支安之。

37. 三台・八座の配置法 ​

由左輔之宮位起初一，順行至生日安三臺。

由右弼之宮位起初一，逆行至生日安八座。

38. 恩光・天貴の配置法 ​

由文昌之宮位起初一，

順行至生日再退一步起恩光。

由文曲之宮位起初一，

順行至生日再退一步起天貴。

39. 天厨の配置法 ​

甲丁食蛇口，乙戊辛馬方。

丙從鼠口得，己食於猴房。

庚食虎頭上，壬雞癸豬堂。

40. 天傷・天使の配置法 ​

天傷在僕役宮，天使在疾厄宮。

41. 長生十二神の配置法 ​

水二局長生在申，

木三局長生在亥，

金四局長生在巳，

土五局長生在申，

火六局長生在寅 ，

陽男陰女順行，

陰男陽女逆行.

安長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕 、胎、養。

42. 博士十二神の配置法 ​

從祿存起，

陽男陰女順行，

陰男陽女逆行。

安博士、力士、青龍、小耗、將軍、奏書、飛廉、喜神、病符、大耗、伏兵、官府。

43. 流年歳前十二神の配置法 ​

流年地支起歲建，歲前首先是晦氣，

喪門貫索及官符，小耗大耗龍德繼，

白虎天德連吊客，病符居後須當記。

44. 流年将前十二神の配置法 ​

寅午戌年將星午，申子辰年子將星，

巳酉丑將酉上駐，亥卯未將卯上停。

攀鞍歲驛並息神，華蓋劫煞災煞輕，

天煞指背咸池續，月煞亡神次第行。

ヒント

流年の地支を基準に将星を置きます。

45. 子斗の算出法 ​

子斗、別名斗君は、流月の正月の起点です。生まれた月と時辰をもとに求めるため、人によって異なり、毎年変わります。

流年歲建起正月，逆逢生月順回程，

回程順至生時止，便是流年正月春。

ヒント

出生月と時間から正月の宮を求め、その後は時計回りに流月を配置します。流月四化は流派で異なり、宮干を直接使う方式も、五虎遁で天干を求める方式もあります。

口訣の解説：流年の地支の宮を正月として生月まで逆に数えます。その宮を子時として出生時辰まで順に数え、斗君を置きます。生年の斗君が定まれば、以後は一年につき一宮ずつ順に進めて求められます。

46. 流日の算出法 ​

以流月所在的宮起初一，

順行十二宮，一日一宮，

到月底最後一天止。

47. 流時の算出法 ​

在流日所在的宮上起子時，順布十二宮，每一個時辰占一宮。

48. 流昌・流曲の配置法 ​

流昌起巳位，甲乙順流去，

不用四墓宮，日月同年歲。

流曲起酉位，甲乙逆行蹤，

亦不用四墓，年日月相同。

注記

中州派以外の流派では、年の曲を使いません。

49. その他の流曜 ​

魁鉞祿羊陀四化加流馬和天盤一樣；

運馬是以大限地支。

流馬是以流年地支。

注記

流曜は通常、大限と流年を中心に見て、流月・流日・流時の流曜は伝統的な解釈ではあまり使いません。ただし、このライブラリはv2.4.4から、この三つの段階の流曜も提供しています。大限の星名には運、流年には流を付けて区別します。例えば、大限の天馬は運馬、流年の天馬は流馬です。

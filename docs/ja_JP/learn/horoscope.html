紫微斗数の運限 ​

運限の種類 ​

本命盤を生まれたときに決まる地図にたとえるなら、運限は、時期に応じてその地図の異なる場所を歩いていく過程です。本命盤はその人の基本的な性質、習慣的な傾向、可能性を表し、運限はそれらの性質がいつ現れやすいかを表します。

紫微斗数の運限は分単位の運限や秒単位の運限まで細分化できます。ただし、細かく見るほど偶然の要因が増え、解釈も実態からずれやすくなります。通常の命盤の解釈では、次の5種類を中心に押さえれば十分です。

  • 大限：1つの大限は10年間を担当し、運限を判断する中心となります。命宮から始まり、陽年生まれの男性と陰年生まれの女性は順行、陰年生まれの男性と陽年生まれの女性は逆行します。最初の大限が何歳から始まるかは、五行局で決まります。
  • 小限：数え年で計算し、1年に1つの宮を移動します。開始位置は、出生年の地支が属する三合局で決まります。男性は順行、女性は逆行します。具体的な配置方法は小限の配置規則を参照してください。
  • 流年：1年間のテーマを示す命盤です。流年の命宮は、その年の地支に対応する宮に置かれ、毎年1つの宮を順行します。その年の流曜と流年四化も生じます。
  • 流月：流年のテーマを月ごとに分けて見ます。すでに兆しがある出来事について、何月に進展しやすいかを観察するのに適しています。大限や流年を考慮せず、流月だけで大きな出来事を判断するのには向いていません。
  • 流日・流時：時間の範囲を、それぞれ1日と1時辰（伝統的な2時間の単位）まで細かくします。通常は時期を選ぶ際や、具体的な出来事を振り返る際に使います。初心者は細かい情報に混乱しやすいため、まず大限と流年の読み方を十分に練習してください。

大限・小限・流年は、互いに置き換えられる3枚の命盤ではありません。大限は10年間の大きな環境を、流年はその年の重点を示し、小限はその年に個人が影響を受けやすい領域を補います。例えば大限が官祿宮に巡っても、10年間毎日仕事のことだけが起こるわけではありません。ただし、その期間には仕事、進む方向、責任、社会的な役割を重点的に観察する価値があります。

『紫微斗数全書』は、大限の開始規則を簡潔にまとめています。

大限由命宮起，陽男陰女順行；陰男陽女逆行，每十年過一宮限。

運限からわかること ​

命盤を手にすると、多くの人がまず「いつ豊かになれるか」「いつ結婚するか」「いつ転職するか」を知りたくなります。こうした問いに答えるには、運限を見る必要があります。本命盤が食材なら、運限は火加減のようなものです。同じ食材でも、火の通し方によって仕上がりは変わります。

運限は、未来を変更できない台本にするためのものではありません。ある時期にどのようなテーマや障害が生じやすいか、どこに注意を向けるべきかを判断する助けになります。少なくとも次の3つの役割があります。

  1. その時期のテーマを見つけます。 大限の命宮が本命盤のどの宮位に巡るかによって、その宮のテーマが強調されます。官祿宮に巡っても必ず昇進するとは限らず、夫妻宮に巡っても必ず結婚するとは限りません。むしろ、その10年間は仕事の方向性、協力関係、親密な関係などに多くの力を注ぐことになりやすい、と捉えます。
  2. 物事が進むタイミングを判断します。 まず大限で「そのような機会があるか」を見て、流年で「今年、その機会が動き出すか」を見ます。小限と流月で時期を絞ります。10年間の流れが土壌を整え、1年間の流れが雨をもたらす、と考えるとよいでしょう。両方の条件がそろうことで、出来事が実現しやすくなります。
  3. リスクと利用できる資源を見極めます。 運限で吉星と吉化がともに会合すると、資源、支援、選択肢が増えることを示す場合が多くあります。煞星や化忌に出会っても、必ず問題が起こるとは限りません。ただし、費用、感情、契約、健康、対人摩擦には一層注意が必要です。リスクを見つけて事前に備えることが、運限を見る最も実用的な意味です。

古典では、大限を論じる際に1つの層だけを見てはいけないと繰り返し強調しています。

須詳大限獨守吉凶何如，小限獨守吉凶何如，太歲獨守吉凶何如。如歲限俱凶則凶。

又看大限與小限相逢吉凶何如，大限逢太歲吉凶何如，小限逢太歲吉凶何如，禍福所定。

現代においてこの文章から学ぶべきなのは、単に「吉凶」という言葉ではなく、その考え方です。流年の化忌が1つあるだけで自分を怖がらせたり、流年の化祿が1つあるだけで何もせず良いことを待ったりしないでください。本命・大限・流年という3つの層の情報が互いに裏付け合うことで、判断はより参考になるものになります。

運限の読み方と活用 ​

運限を見る際に避けたいのは、本命盤を飛ばして、ある年に定型的な占断をそのまま当てはめることです。地図も天気も見ず、カレンダーだけで出かけるかどうかを決めるようなもので、精度は高くなりません。より堅実な順序は次のとおりです。

  1. まず本命盤を見ます。 命宮・身宮・十二宮の基本的な性質を理解し、特にどの分野が自分の強みで、どの課題に繰り返しつまずきやすいかを把握します。本命盤という土台がなければ、運限を具体的に読み取れません。
  2. 次に大限の命宮とその三方四正を見ます。 大限の命宮が本命盤のどの宮位にあるかを確認し、その宮の主星・輔星・煞星や化忌・本命の四化を見ます。そのうえで、大限の命宮の三方四正を調べます。これらから10年間の主な流れを読み取るため、1つの宮位だけで結論を出さないでください。
  3. 流年を重ねます。 その年の出来事を判断するには、流年の命宮が大限の命盤のどこにあるか、流年の四化がどこに入るか、流曜が本命盤や大限の重要な宮位を活性化するかを見ます。大限が良く流年が平凡なら、着実に積み重ねる時期になることが多くあります。大限の負担が大きくても、流年に吉化があれば、プレッシャーの中で突破口を見つける可能性があります。
  4. 最後に小限と流月で時期を絞ります。 10年間に取り組むことと、その年に起こりそうなことが大まかに分かったら、小限と流月でより具体的な時期を見ます。小限には独立した流曜がありません。ライブラリでは、その宮の宮干から小限の四化を計算しますが、もう一つの独立した流年盤として扱わないでください。

具体的な例を挙げます。大限の命宮が本命盤の官祿宮に入り、流年の化祿・化權が官祿宮や遷移宮に会合する場合、その年は役職、プロジェクト、顧客、より広い活躍の場を積極的に求めるのに比較的適しています。同時に煞星や化忌も関わるなら、大きな機会と大きな負担が一緒に来ることがあります。このとき有益なのは「必ず昇進する」「必ず不運になる」と断言することではありません。事前に能力を補い、権限と責任を確認し、ペースを調整して、機会が過度な消耗につながらないようにすることです。

ヒント

運限を見る際は、今起こっていることを記録し、1〜2年後に振り返って解釈と照らし合わせることをお勧めします。紫微斗数は穴埋め問題ではありません。命盤が示すのは通常、傾向や状況です。機会の選び方やリスクへの対処によって、出来事が最終的にどのような形で現れるかは変わります。

最後にもう一度、運限は不安をあおるためのものではありません。良い年と読めたら、しっかり準備して積極的に機会をつかみましょう。負担の大きい年と読めたら、重大な判断を急がず、資金と気力に余裕を残してください。これを実践するほうが、定型的な占断を暗記するだけよりもはるかに役立ちます。

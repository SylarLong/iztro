運限 ​

^2.6.2 運限の取得には、命盤の生成時に保存された設定と言語が使われます。グローバルの既定値を変更したり別の命盤を作ったりしても、既存の命盤での取得結果は変わりません。horoscope()には有効なDateオブジェクトか日付文字列を渡せます。日付を省略すると、呼び出し時の現在時刻を使います。時刻のインデックスを明示する場合は0～12の整数が必要です。無効な日付や時刻インデックスはエラーになります。

はじめに ​

紫微斗数の運限には、大限、小限、流年、流月、流日、流時、分単位の運限、秒単位の運限などがあります。概念と活用法は運限の説明をご覧ください。iztroは大限、小限、流年、流月、流日、流時を提供します。そのうち大限、流年、流月、流日、流時には流曜と四化があります。流月、流日、流時の流曜はv2.4.4から提供されています。小限には独立した流曜がなく、小限の四化はその宮の宮干から計算されます。

ヒント

運限の年・月の干支の切り替わりは、命盤に保存されたhoroscopeDivideの設定に従います。小限の数え年の切り替わりはageDivideで決まります。

クラスと分析メソッド ​

開発提案

運限は命盤に基づくため、newで直接生成するより、命盤のインスタンスから取得してください。命盤のhoroscope()メソッドが運限のオブジェクトを返します。

ts
import { astro } from "iztro";

const astrolabe = astro.astrolabeBySolarDate("2000-8-16", 2, "女", true, "zh-CN");
const horoscope = astrolabe.horoscope('2023-10-26', 2);

上記のコードを実行すると、FunctionalHoroscope のインスタンスが返されます。

FunctionalHoroscope ​

implements IFunctionalHoroscope extends Horoscope

このクラスのプロパティはすべてHoroscopeから継承され、インターフェースには運限の星曜を分析するメソッドが加わります。

  • インターフェースの定義

    ts
    interface IFunctionalHoroscope extends Horoscope {
  toJSON: () => Horoscope;
  agePalace: () => FunctionalPalace | undefined;
  palace: (palaceName: PalaceName, scope: Scope) => FunctionalPalace | undefined;
  surroundPalaces: (palaceName: PalaceName, scope: Scope) => FunctionalSurpalaces | undefined;
  hasHoroscopeStars: (palaceName: PalaceName, scope: Scope, horoscopeStar: StarName[]) => boolean;
  notHaveHoroscopeStars: (palaceName: PalaceName, scope: Scope, horoscope: StarName[]) => boolean;
  hasOneOfHoroscopeStars: (palaceName: PalaceName, scope: Scope, horoscopeStar: StarName[]) => boolean;
  hasHoroscopeMutagen: (palaceName: PalaceName, scope: Scope, horoscopeMutagen: Mutagen) => boolean;
}
    ^2.6.1 palaceNameには、命盤の出力言語にかかわらず、設定されたどの言語の宮名でも渡せます。例えば、中国語で出力する命盤にも英語の宮名"soul"を指定できます。

  • プロパティ

    参照 Horoscope

  • メソッド

    toJSON() ^2.6.0 ​

    • 目的

      機能付き運限のオブジェクトを通常のJSONオブジェクトに変換します。分析メソッドや所属する命盤などの実行時参照は含めず、循環参照も安全に除外します。

    • 定義

      ts
      type toJSON = () => Horoscope;

    • パラメータ

      なし

    • 戻り値

      Horoscope

    • 使用例

      ts
      import { astro } from "iztro";

const astrolabe = astro.bySolar("2000-8-16", 2, "女");
const data = astrolabe.horoscope("2023-8-19").toJSON();

      ts

    • 使用例
